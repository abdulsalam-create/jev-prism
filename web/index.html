Jev Pipeline

A decision pipeline built on TypeSafe's Jev model. Stage 1 triages the ticket with a choice + score + noul. The app then reads the choice and, in code, routes to a team-specific stage 2 with different questions. Each run makes real, live Jev calls through the local backend, so the key stays on your machine.
