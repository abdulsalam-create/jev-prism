Prism

One piece of text, split into typed decisions by TypeSafe's Jev.

Most language models answer in prose you then have to parse. Jev answers in types. Ask it a question about some text and it returns a decision you can branch on directly, with the probabilities behind it:

choicepicks one labelled option - routing, classification, triage.
scorerates against an ordered rubric; the value lands between levels, weighted by probability.
noula single yes/no probability from 0 to 1 - gates and flags.
Built on TypeSafe Jev · POST /v1/systemone source + live-proxy setup on GitHub

Go live

Jev's API blocks browser calls (CORS), so the showcase above replays real responses captured from the API. To run your own text, point Prism at a tiny proxy that holds your key server-side.

The repo ships a Cloudflare Worker you deploy in two commands. Your key lives as a Worker secret - never in this page, never in the repo. Paste the Worker URL here; it is stored only in this browser.
